视网膜母细胞瘤（ ， ）是儿童最常见的眼内恶性肿瘤， 患者 岁以内发病，新生儿发病率为 $1 : 1 6 0 0 0 { \sim } 1 8 0 0 0 ^ { [ 1 - 2 ] }$ 。在 患者中，遗传型约占 $40 \%$ ，非遗传型约占 $60 \%$ ； $10 \%$ 有家族史，$90 \%$ 为散发［3］ 。双眼患者占 $2 0 \% \sim 3 0 \%$ ，单眼患者占 $7 0 \% \sim 8 0 \% ^ { [ 4 ] }$ 。 主要因 基因突变或缺失引起。 在一段时间内局限于眼球内，称为眼内期；肿瘤突破筛板、巩膜等浸润视神经和眼眶组织，称为眼外期；肿瘤转移至颅内、血液或淋巴结，称为转移期。眼内期 若能得到规范治疗，绝大多数患者可实现保生命，多数患者实现保眼球，部分患者实现保视力。不同阶段 、单侧和双侧 的治疗方案多有不同，加之我国各地区医疗水平不均衡， 的治疗效果差异较大。鉴于 患者就诊时以单侧眼内期为主，中华医学会眼科学分会眼整形眼眶病学组与相关专家经过认真讨论，共同提出单侧眼内期 诊疗专家共识，以期提高我国 的治疗水平，改善患者预后和生活质量。

# 一、眼内期RB的主要临床表现

症状：早期难以发现。随着肿瘤不断增大，经瞳孔可见黄白色反光，即“白瞳症”，为最常见临床表现；部分患者因视力低下出现知觉性外斜视，继发青光眼患者出现眼红、疼痛等症状。  
眼底检查：采用双目间接检眼镜或数字化广域眼底成像系统（ ）检查，可见视网膜单个或多个隆起病灶，初起呈灰色半透明样表现，随着肿

瘤直径增大到 $4 \sim 5 ~ \mathrm { m m }$ ，颜色变为不透明白色或黄色，肿瘤表面视网膜血管扩张、出血。肿瘤的生长方式分为两种：（）肿瘤由视网膜外核层向视网膜下间隙生长，常伴视网膜下积液或种植，出现非孔源性视网膜脱离，称为外生性肿瘤；（）肿瘤由视网膜内核层向内生长，突向玻璃体腔，常伴有肿瘤细胞玻璃体腔内播散种植，称为内生性肿瘤。

影像学检查： 超、 和 均可发现眼内占位性病灶。 超可简易判断肿瘤体积、位置、是否钙化、是否视网膜脱离； 可明确肿瘤体积和范围，对肿瘤的定位和钙化灶识别优于 超；当肿瘤直径超过 $1 0 ~ \mathrm { m m }$ ，肿瘤中心常会出现自发性出血、坏死或钙化。 对软组织分辨率高，可以显示肿瘤的位置、体积和血液供应程度等，并有助于判断是否存在巩膜或视神经浸润。

超声检查：玻璃体腔内可见 个或多个大小不等的圆形、类圆形或不规则形病变，病变边界不整齐，内回声中等、不均匀。由于肿瘤组织容易坏死或局部钙质沉着，故肿瘤内可出现小片状无回声腔和强回声斑块，其后有声影。彩色多普勒超声检查除 超检查表现特征外，可见肿瘤内部有丰富的红蓝色血流信号，为分枝状，由视网膜中央动脉供血，呈高速高阻动脉频谱。

检查：水平扫描玻璃体腔内可见与球壁相连的大小不一、形状不规则的高密度块影，边界不清、不均质，约 $7 5 \%$ 肿瘤内可见形状不规则的骨密

度影，为钙化斑，此为典型的CT征。若肿瘤侵犯视神经，可见视神经增粗，视神经管扩大及肿瘤颅内蔓延。肿瘤经巩膜向眼外蔓延者，可见眶内高密度肿块与眼内病变相连，眼球壁连续性破坏。

MRI检查： $\mathrm { T } _ { 1 } \mathrm { W I }$ 呈中信号， $\mathrm { T } _ { 2 } \mathrm { W I }$ 呈高信号。肿瘤内钙化斑在 $\mathrm { T } _ { 1 } \mathrm { W I }$ 和 $\mathrm { T } _ { 2 } \mathrm { W I }$ 上均表现为低信号。根据肿瘤的体积不同，肿瘤信号可呈斑驳状，信号均偏低或显示为中低信号。肿瘤沿视神经向颅内蔓延时，MRI检查可清晰显示肿瘤在眶内及颅内的范围，优于CT检查。

# 二、眼内期RB的组织病理学特点

组织病理学检查是 确诊的依据，也是确定患者组织病理学分期及是否存在组织病理学高危因素的重要方法。 组织病理学表现可分为未分化型和分化型，未分化型 细胞核深染，形态大小不一，呈圆形、椭圆形、梭形或异形，细胞质极少，核分裂象多见。分化型 细胞形成菊花团样结构，称 菊花团，是 最具特征性的组织病理学改变。 年国际 分期工作组（Retinoblastoma Staging Working Group，IRSWG）将肿瘤侵犯视神经，包括侵犯筛板前、筛板、筛板后和视神经切除断端以及脉络膜定义为 的组织病理学高危因素，建议此类患者眼球摘除后进行全身辅助性化学治疗［5］。

# 三、眼内期 的临床诊断

根据发病年龄大多在 岁以内，有家族史，白瞳、斜视等典型症状，眼底黄白色病灶、视网膜下或玻璃体腔播散灶、视网膜脱离，影像学检查眼内实性占位病变、钙化等，可做出临床诊断。

需要与其他可以引起“白瞳症”的疾病相鉴别，主要包括 病、眼内炎、永存原始玻璃体增生症和早产儿视网膜病变等。

# 五、单侧眼内期 治疗

# （一）治疗基本原则

治疗的基本原则依次为保生命、保眼球、保视力，在不影响生存率的前提下尽量保眼球和保视力。

# （二）主要治疗方法

化学治疗仍是目前眼内期 的一线治疗方法，根据注药途径分为静脉化学治疗、动脉化学治疗和玻璃体腔注药化学治疗，其他治疗方法包括局部治疗和手术治疗。局部治疗包括激光光凝治疗、冷冻治疗、经瞳孔温热治疗等；手术治疗主要为眼球摘除术。

# 静脉化学治疗

采用长春新碱（ ， ）、依托泊苷（Etoposide，VP16）和卡铂（Carboplatin，Carbo）联合的 方案。 岁以下患者用药剂量：长春新碱每千克体重 $0 . 0 5 ~ \mathrm { m g }$ 静脉推注，第1天；依托泊苷每千

克体重 $5 ~ \mathrm { m g }$ 静脉滴注，第1、2天；卡铂每千克体重$1 8 . 6 ~ \mathrm { m g }$ 静脉滴注，第 天。 岁以上患者用药剂量：长春新碱 $1 . 5 ~ \mathrm { m g } / \mathrm { m } ^ { 2 }$ （体表面积）静脉推注（最大剂量 $2 \ : \mathrm { m g }$ ），第1天；依托泊苷 $1 5 0 \mathrm { m g } / \mathrm { m } ^ { 2 }$ （体表面积）静脉滴注，第1、2天；卡铂 $5 6 0 ~ \mathrm { m g } / \mathrm { m } ^ { 2 }$ （体表面积）静脉滴注，第 天。一般每 周 次，共 次。

# 2.动脉化学治疗

动脉化学治疗是通过股动脉插管，经颈内动脉至眼动脉后，将化学治疗药物直接灌注至眼内。与静脉化学治疗相比，具有肿瘤局部药物浓度高、杀伤效果强和不良反应轻等优点。所用药物主要为马法兰（ ）、卡铂和托普替康。一般每 $3 \sim$ 周 次，共 次。 $5 0 \mathrm { m g }$ 马法兰使用自带的 $1 0 ~ \mathrm { m l }$ 溶媒溶解后，根据患者年龄和体重采用相应的剂量（表1）；卡铂直接 $2 0 ~ \mathrm { m g }$ 加生理盐水 $3 0 ~ \mathrm { m l }$ 稀释；托普替康使用 $2 ~ \mathrm { m l }$ 注射用水溶解后，再按 $1 ~ \mathrm { m g }$ 加生理盐水 $3 0 ~ \mathrm { m l }$ 稀释；每组溶液分别按照 $3 0 ~ \mathrm { m l / 1 5 \sim }$ $3 0 ~ \mathrm { m i n }$ 的速度行眼动脉灌注。第 次：马法兰 $^ +$ 卡铂 $2 0 ~ \mathrm { m g }$ ；第2次：马法兰 $^ +$ 托普替康 $1 ~ \mathrm { m g }$ ；第3次：马法兰 $^ +$ 卡铂 $2 0 \mathrm { m g }$ ；第4次：马法兰 $^ +$ 托普替康 $1 ~ \mathrm { m g }$ 。

# 玻璃体腔化学治疗

将化学治疗药物（马法兰、托普替康等）直接注入到玻璃体腔内，适用于伴有玻璃体肿瘤播散种植的患者。注射前 ，患眼点抗生素滴眼液 次 ；注射前聚维酮碘冲洗结膜囊；常规消毒铺巾，暴露患眼后，抽取新鲜配置的马法兰或托普替康，根据肿瘤和肿瘤细胞播散的位置选择注射部位，使用32 G注射针头于角膜缘后 $1 . 0 { \sim } 2 . 5 ~ \mathrm { m m }$ 进针，将药物注入玻璃体腔；注射部位 次冻融冷凝治疗，或结膜下注射马法兰或托普替康后拔针，棉签按压注射部位 ；轻轻转动眼球使药物分散，避免局部聚集导致视网膜毒性；注射后继续点用抗生素和糖皮质激素滴眼液 $3 { \sim } 4 \mathrm { d } ^ { [ 1 2 - 1 3 ] }$ 。

# 激光光凝治疗

适用于赤道部后体积较小的肿瘤。利用激光的热凝固作用，直接杀伤肿瘤细胞。临床采用的激光波长为 、 和 $1 0 6 4 \mathrm { n m }$ 。激光的波长与组织穿透能力成正比。 $5 3 2 \mathrm { n m }$ 激光的组织穿透能力较低，深度为 $2 { \sim } 3 ~ \mathrm { m m }$ ，用于治疗较薄的肿瘤； $8 1 0 ~ \mathrm { n m }$ 激光的组织穿透厚度为 $4 { \sim } 5 \ \mathrm { m m }$ ，用于治疗体积较小的肿瘤； $1 \ 0 6 4 \ \mathrm { n m }$ 激光的穿透能力强，适合于治疗体积较大的肿瘤。在双目间接检眼镜直视下，激光光凝范围覆盖瘤体。参数设置：功率从 $1 0 0 ~ \mathrm { m W }$ 起，逐渐增加；曝光时间为 $0 . 5 { \sim } 2 . 0 ~ \mathrm { s }$ ，至肿瘤达到Ⅳ级光斑反应为宜。

# 5.冷凝治疗

主要用于治疗赤道部及周边部的小肿瘤。$- 8 0 ~ \mathrm { { ^ \circ C } }$ 二氧化碳为冷凝源。一般冷凝至肿瘤变为冰球样改变，冻融后再冷凝，每点冷凝 或 次。

# 眼球摘除

主要用于具有 临床高危因素的 期患眼。手术剪除视神经的长度要尽可能长，至少 $1 0 ~ \mathrm { m m }$ ，以防止视神经残端有肿瘤残留。

# （三）治疗方案

除了极少数非常早期的患眼可以使用单一的治疗方法外，绝大多数患者需要采取综合治疗方案。治疗方案主要依据肿瘤的分期、部位及生长方式等制定。在治疗过程中，还需根据患眼对治疗的反应和病情变化及时调整治疗方案。

期：激光光凝治疗或冷凝治疗。

期（肿瘤与黄斑中心凹距离 $> 3 . 0 \ \mathrm { m m }$ 且与视盘距离 ${ \mathrm { > } } 1 . 5 ~ \mathrm { m m }$ ）：冷凝治疗或激光光凝治疗，必要时采用静脉化学治疗。  
期（肿瘤与黄斑中心凹距离 $\leqslant 3 . 0 \ \mathrm { m m }$ 或与视盘距离 $\leqslant 1 . 5 \mathrm { m m }$ ）：静脉化学治疗，辅以激光光凝治疗或冷凝治疗。  
期：静脉化学治疗或动脉化学治疗 $^ +$ 激光光凝治疗、冷凝治疗或玻璃体腔化学治疗。  
期：动脉化学治疗或静脉化学治疗 $^ +$ 激光光凝治疗、冷凝治疗或玻璃体腔化学治疗，必要时摘除眼球。  
期（无 临床高危因素）：摘除眼球（根据术后组织病理学检查结果，确定是否进行静脉化学治疗）；动脉化学治疗或静脉化学治疗 $^ +$ 激光光凝治疗、冷凝治疗或玻璃体腔化学治疗。  
期（伴 临床高危因素）：摘除眼球，根据术后组织病理学检查结果，确定是否进行静脉化学

治疗。

# （四）治疗期间注意事项

1. 化学治疗结束后每周至少进行2次血液常规检查，检测骨髓抑制情况，若白细胞、血红蛋白或血小板数量过低，需进行粒细胞集落刺激因子治疗或输注成分血；每次化学治疗前进行血液常规检查、肝肾功能和听力检查。  
2.每个月进行眼底检查，观察肿瘤是否萎缩或钙化，是否出现眼部并发症，如出血、视网膜脱离等，评判治疗效果。  
若在治疗周期内肿瘤仍持续进展，则需要调整治疗方案。

# （五）随访

肿瘤控制稳定后每 个月检查 次眼底；稳定2年以上可改为每3~6个月检查1次眼底，直至成年。  
眼球摘除术后，无 临床高危因素患眼每年进行 次 检查，年后根据情况选择是否行检查；伴有 临床高危因素患眼，全身辅助性化学治疗后，每 个月进行 次 检查，年后改为每年进行 次 检查至成年。

在随访过程中出现肿瘤复发或出现新的肿瘤病灶，根据分期再次进行治疗。若无法控制肿瘤发展，则需要更换治疗方案，甚至摘除眼球。化学治疗后 个月内避免接种预防疫苗。随访过程中，应同时行对侧眼检查。
